# 간성초등학교 AI 연수

컴퓨터 전체화면에서 사용하는 27개 장면의 인터랙티브 연수 프레젠테이션입니다. 모션 그래픽, 파티클, 스크롤 이동과 발표자 재생 제어를 포함합니다.

## 실행

Python 3가 설치된 컴퓨터에서 저장소 폴더를 열고 실행하세요.

```sh
python -m http.server 8509 --bind 127.0.0.1 --directory dist
```

브라우저에서 http://127.0.0.1:8509/index.html 을 열고 전체화면으로 전환하세요.

## 발표자 조작

- 상단 번호, 이전·다음 버튼, 방향키 및 스크롤로 장면을 이동합니다.
- 재생·일시 정지, 다시 보기, 슬라이더와 완료 화면 버튼으로 현재 장면을 제어합니다.
- 각 장면은 완료 상태에서 유지되며, 다음 장면은 발표자가 이동합니다.
- 소리와 모션 설정은 화면 오른쪽 위에서 조절합니다.

## 구성

학교 타이틀과 목차, AI를 대하는 자세, 설치 및 기본 활용, 다섯 가지 AI 활용 팁, 실습과 마무리 순서입니다. 실습 그래픽은 설명용이며 실제 AI 서비스 호출이나 설치를 수행하지 않습니다.

런타임은 `dist/`에 포함되어 있습니다. 외부 API 키나 패키지 설치가 필요하지 않습니다. 포함된 Three.js, GSAP 및 Pretendard의 라이선스·고지는 `dist/vendor/`에, 물음표 자산 고지는 `dist/assets/`에 있습니다.
